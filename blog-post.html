[Post Title — Dynamic from LinkedIn Feed]

This page serves as the template for individual blog posts. When a user clicks "Read More" from a LinkedIn post card, the content is populated dynamically from the LinkedIn API response stored in the cache file.

Each post displays the full content text from LinkedIn, the post date, category, and a link back to the original LinkedIn post for interaction (likes, comments, shares).

How This Works

Posts are fetched via /api/linkedin-feed.php and cached in /api/linkedin-cache.json. The JavaScript in linkedin-feed.js reads the post data and populates this template when a specific post is requested via URL parameter (e.g., blog-post.html?id=post-id-here).

For full implementation, the blog-post page would read the ?id or ?slug query parameter and match it against the cached posts to render the full content.
